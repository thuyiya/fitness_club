# 08 --- Meal Plans

## Meal plan

A coach can create:

-   breakfast
-   morning snack
-   lunch
-   evening snack
-   dinner
-   custom meal

Each item can contain:

-   food
-   serving
-   calories
-   protein
-   carbohydrates
-   fat
-   notes
-   photo/reference image

## Coach workflow

1.  Create meal plan
2.  Add meals
3.  Set targets
4.  Save
5.  Assign to members

## Member workflow

-   See today's meals
-   Mark meal completed
-   Log actual meal
-   Upload photo
-   Add calories if known
-   Add note
-   Submit to coach

## Important product decision

A planned meal and an actual meal log are different records.

Example:

`Planned lunch: chicken + rice + vegetables`

`Actual lunch: uploaded photo + estimated 620 kcal`

This gives the coach visibility into adherence without overwriting the
original plan.
