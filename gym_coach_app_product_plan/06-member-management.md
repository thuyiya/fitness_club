# 06 --- Member Management

## Member list

Filters:

-   All
-   Active
-   Needs attention
-   No plan
-   Inactive

Search by name.

## Member card

Show:

-   photo
-   name
-   current plan
-   completion status
-   latest weight
-   last activity
-   attention indicator

## Member profile sections

-   Overview
-   Plan
-   Activity
-   Nutrition
-   Progress
-   Health
-   Notes
-   Chat

## Attention examples

-   Workout missed
-   No meal logged
-   Weight not updated
-   No activity for several days
-   Plan ending soon
-   Unread member message

The coach should be able to understand the situation without opening
every metric.
