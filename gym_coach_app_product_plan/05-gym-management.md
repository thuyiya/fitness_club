# 05 --- Gym Management

## Coach capabilities

A coach can:

-   create a gym
-   edit gym details
-   add multiple locations
-   switch between locations
-   see all gyms
-   see member counts
-   archive a gym

## Gym card

Show:

-   gym name
-   location
-   photo
-   active members
-   plans in progress
-   members needing attention

## Active context

The dashboard should clearly show the selected gym.

Example:

`City Fitness — Main ▾`

Switching the gym changes member and dashboard context.
