# 07 --- Workout Plans

## Plan structure

``` text
Plan
 ├── metadata
 ├── Week 1
 │    ├── Day 1
 │    │    ├── Exercise
 │    │    ├── Exercise
 │    │    └── Exercise
 │    └── Day 2
 └── Week 2...
```

## Exercise fields

-   name
-   category
-   muscle groups
-   equipment
-   instructions
-   image
-   video
-   sets
-   reps
-   duration
-   rest
-   target weight/load
-   tempo
-   coach note

## Plan builder UX

1.  Plan name
2.  Duration
3.  Goal
4.  Build weekly schedule
5.  Add exercises
6.  Configure sets/reps
7.  Preview member experience
8.  Save as plan or template
9.  Assign to members

## Member workout experience

Today's workout should show:

-   workout title
-   estimated duration
-   exercise count
-   progress
-   exercise image/video
-   instructions
-   sets/reps
-   rest timer
-   complete button

Keep the member experience focused on one exercise at a time when the
workout starts.
