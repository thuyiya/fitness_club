# 04 --- Authentication & Onboarding

## Coach onboarding

1.  Welcome
2.  Create account
3.  Name + profile photo
4.  Create first gym
5.  Gym name + location
6.  Add optional second gym
7.  Dashboard

## Member onboarding

1.  Invite link/code or direct signup
2.  Create account
3.  Basic profile
4.  Goals
5.  Current weight/height where appropriate
6.  Join coach/gym
7.  Connect Apple Health --- optional
8.  See assigned plan

## UX principle

Do not ask for every detail during onboarding. Capture the minimum
required information and let the coach/member complete the profile
later.

## Account states

-   invited
-   active
-   suspended
-   archived

## Security

Use secure authentication tokens. Never trust role information sent only
by the client.
