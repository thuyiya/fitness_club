# 15 --- Asset Inventory

The app needs a deliberate asset system before implementation.

## 1. App brand assets

-   App logo
-   App icon
-   Splash/launch graphic
-   Light logo
-   Dark logo
-   monochrome logo
-   favicon/web asset if a web admin is added

Recommended formats:

-   SVG for UI logos/icons
-   PNG for platform-specific exports
-   high-resolution source files

## 2. Exercise images

Need a consistent illustration/photo style.

For every exercise:

-   primary image
-   optional alternate angle
-   short instruction sequence
-   muscle-group metadata
-   equipment metadata
-   difficulty
-   optional video

### Exercise image rules

The visual style must remain consistent across the entire library.

Possible direction:

-   clean fitness photography OR
-   minimalist anatomical/fitness illustration

Do not mix random visual styles.

## 3. Exercise videos

Short clips:

-   5--20 seconds
-   correct technique
-   neutral background
-   no unnecessary branding
-   portrait-friendly crop where possible

Video should be optional; images + instructions must still work.

## 4. Meal images

Need:

-   generic food reference photos
-   meal-category images
-   optional food-library thumbnails

Members can upload their own meal photos.

User-generated photos need:

-   compression
-   upload progress
-   retry
-   privacy controls

## 5. Gym images

-   gym cover image
-   optional location photo
-   equipment images if used later

## 6. Profile photos

-   coach avatar
-   member avatar

Support default avatar placeholders.

## 7. Icons

Use one consistent icon system.

Recommended categories:

-   Home
-   Members
-   Plans
-   Gyms
-   Progress
-   Nutrition
-   Workout
-   Chat
-   Notifications
-   Health
-   Settings
-   Add
-   Search
-   Filter
-   Calendar
-   Camera
-   Photo
-   Video
-   Weight
-   Steps
-   Calories
-   Heart
-   Sleep
-   Water
-   Check
-   Warning
-   More

Use vector icons rather than emoji for core navigation.

## 8. Emojis

Emojis can be used for friendly micro-interactions, not core navigation.

Examples:

-   👋 greeting
-   🔥 streak
-   💪 workout
-   🥗 nutrition
-   💧 water
-   ❤️ health
-   🎯 goal
-   ✅ completion
-   🏆 milestone

Keep emoji use restrained so the product still feels professional.

## 9. Illustrations

Useful for:

-   empty states
-   no plan assigned
-   no workouts today
-   health not connected
-   no messages
-   first-time onboarding
-   success/completion

## 10. UI motion

Small animations:

-   workout completion
-   progress ring
-   plan completion
-   checkmark
-   pull-to-refresh
-   upload progress

Avoid excessive gamification.

## Asset naming

Use predictable names:

`exercise_pushup_01.webp`

`exercise_pushup_instruction_01.webp`

`meal_chicken_rice_01.webp`

`icon_workout.svg`

`illustration_no_plan.svg`

## Asset delivery

Create an asset manifest containing:

-   asset ID
-   type
-   filename
-   dimensions
-   format
-   source/license
-   usage
-   version
