# Calisthenics Exercise Catalog

Calisthenics uses body weight as the main resistance. This catalog covers common exercises, progressions, static holds, and advanced skills, including movements performed with bars, rings, benches, or other supports. No list can include every possible variation: grips, leverage, range of motion, tempo, and combinations create additional versions.

**Approximate levels:** Beginner (B), Intermediate (I), Advanced (A), Elite (E). Difficulty depends on the variation and individual ability; these labels are not prerequisites or a training prescription. Assisted versions use a band, support, or partner. Weighted versions are optional extensions of the exercises below.

## Equipment Reference

| Equipment | Typical exercises |
| --- | --- |
| None / floor | Push-ups, squats, lunges, planks, bridges, crawls, jumps |
| Wall | Wall push-ups, wall sits, handstand drills, tibialis raises |
| Stable bench, step, or box | Incline push-ups, step-ups, split squats, box jumps |
| Pull-up bar | Pull-ups, hangs, hanging raises, bar muscle-ups, levers |
| Low bar | Inverted rows, bodyweight curls, triceps extensions |
| Parallel bars / dip bars | Dips, support holds, L-sits, leg raises |
| Parallettes | L-sits, planches, handstands, deficit push-ups |
| Gymnastic rings | Rows, push-ups, dips, muscle-ups, ring strength holds |
| Rope or towel | Grip hangs, pull-ups, rope climbs |
| Sliders or a smooth surface | Hamstring curls, body saws |
| Secure ankle anchor | Nordic hamstring curls |
| Vertical pole / suitable ladder | Human flags |
| Resistance band | Assistance for pull-ups, dips, muscle-ups, and skills |

## Ways to Extend the Catalog

Many exercises can also be performed with assistance, slower negatives, pauses, isometric holds, different grips, reduced or increased range of motion, unilateral loading, or added weight. These are variations of the same exercise family rather than an exhaustive set of separate exercises.
